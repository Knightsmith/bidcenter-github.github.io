- 横条固定展示 9 项：今天 + 1天后 ~ 8天后（含周六日，与表格行一一对应）。

- 横条首项「今天」保留，不同步表格的天数口径。

**数据来源**：**空**（回访数量统计）。演示值：42 / 38 / 37 / 41 / 30 / 12 / 6 / 36 / 34。

### 需求 4：级别筛选联动

**位置**：页面上方筛选区「选择客户评级」下拉（宽 160px），与回访日程卡片联动。

**级别 → 天数对应**：

| 级别 | 含义 | 工作日天数 |
|---|---|---|
| AA | 待打款 | 1 |
| A | 已明确办理 | 2 |
| B | 计划合作 | 3 |
| C | 有考虑需挖掘 | 5 |
| D | 意向不明确 | 7 |
| E | 明确不合作 | 7 |

**联动逻辑**：

1. 选择级别后，表格中该等级列整体强化（表头蓝底白字、单元格浅蓝底蓝字加粗）；未选择无强化。
2. 切换级别即回到收起态，按钮恢复「展开」。

---

### 需求 5：展开 / 收起与天数计算口径（核心）

**按钮**：卡片标题右侧「展开」/「收起」（文案不带天数）。

**计算口径**：

1. **天数从明天起数工作日，跳过周六日，不含今天**。
2. **展示含今天行**：展示范围 = 今天 + 从明天起 N 个工作日（截止行之前的周六日行照常显示，带周末绿底绿字）。
3. 级别天数 N 按上表（AA=1 / A=2 / B=3 / C=5 / D=7 / E=7）。

**各状态展示**：

| 状态 | 展示内容 |
|---|---|
| 初始（未选级别、收起） | 全部收起，仅表头 |
| 选择 AA 级（收起） | 今天 + 明天共 **2 行**（如 10-19、10-20） |
| 选择 C 级（收起） | 今天 + 明天起 5 个工作日 → 截止 10-26，展示 10-19~10-26（含 10-24/25 周末行） |
| 选择 D / E 级（收起） | 今天 + 明天起 7 个工作日 → 截止 10-28，展示 10-19~10-28 共 10 行 |
| 点击「展开」（无论是否选级别） | 今天 + 明天起 7 个工作日 → 截止 10-28，展示 10-19~10-28 共 **10 行**；按钮变「收起」 |
| 点击「收起」 | 按当前级别回到对应收起态（未选级别则全收起） |

**示例（演示日期 2026-10-19 周一）**：

- AA 级：显示 10-19（今天）+ 10-20（明天）= 2 行。
- C 级：显示 10-19 ~ 10-26，其中 10-24（周六）、10-25（周日）为周末行，共 8 行。
- 展开：显示 10-19 ~ 10-28 共 10 行（含 24/25 周末行）。

---

**权限**：销售（默认），仅本人客户。

**数据来源**：**空**（回访日程接口）。演示值：14 行分等级数量（10-19 ~ 11-01），合计 >40 标红演示 42 / 41 / 43。

## 4. 验收要点

1. 回访日程为独立卡片：标题 + 副标题 + 「展开」按钮 + 每日横条 + 表格。
2. 横条 9 项（今天 + 1~8 天后），当天过多红色（`#e8443a`）、周末绿色（`#1fa35a`），尾部有红色提示。
3. 等级列黑白统一：灰表头（`#8d96a5` / 底 `#f4f6f9`）黑数字（`#333`）。
4. 选择级别后该列强化：表头蓝底白字、单元格浅蓝底（`#eaf5fd`）蓝字（`#1f6fb2`）加粗。
5. 合计 >40 标红（`#e8443a`）。
6. 天数从明天起数工作日、不含今天，展示含今天：AA 级显示今天+明天共 2 行；展开显示 10-19~10-28 共 10 行；未选级别收起仅表头。
7. 周末行绿底（`#f1faf4`）绿字（`#1fa35a`）；按钮文案为「展开」/「收起」，不带天数。
