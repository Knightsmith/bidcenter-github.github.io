# 数据统计埋点规范

## 一、采集事件

| 事件 | 采集内容 |
|---|---|
| 用户注册 | 用户标识、注册时间、注册来源 |
| 短信发送 | 用户标识、短信类型、发送时间、计费条数 |
| 短信打开 | 用户标识、短信类型、打开时间 |
| 短链点击 | 用户标识、短信类型、点击时间 |
| 落地页浏览 | 用户标识、来源短信、浏览时间 |
| 进入付费申请 | 用户标识、来源短信、浏览时间 |
| 支付成功 | 用户标识、支付金额、支付时间、归因短信 |

## 二、统计指标

| 指标 | 统计字段（口径） | 计算方式 |
|---|---|---|
| 注册用户数 | 注册用户数（按用户标识去重） | 注册事件去重计数 |
| 发送短信量 | 发送短信条数 | 短信发送事件计数 |
| 短信打开数量 | 短信打开条数 | 短信打开事件计数 |
| 短信打开率 | 短信打开条数 ÷ 发送短信条数 | 打开 ÷ 发送 |
| 短链点击数量 | 短链点击条数 | 短链点击事件计数 |
| 短链点击率 | 短链点击条数 ÷ 发送短信条数 | 点击 ÷ 发送 |
| 落地页浏览用户数 | 落地页浏览用户数（按用户标识去重） | 浏览事件按用户去重 |
| 进入付费申请用户数 | 进入付费申请用户数（按用户标识去重） | 进入事件按用户去重 |
| 支付成功用户数 | 支付成功用户数（按用户标识去重） | 支付事件按用户去重 |
| 全链路转化率 | 支付成功用户数 ÷ 短链点击用户数 | 支付 ÷ 点击 |
| 短信打开链路转化率 | 短链点击条数 ÷ 发送短信条数 | 点击 ÷ 发送 |
| 增量转化率 | 归因支付用户数 ÷ 发送短信条数 | 归因支付 ÷ 发送 |
| 支付环比 | 本周支付成功用户数 vs 上周 | （本周 − 上周）÷ 上周 |

## 三、归因规则

1. **归因窗口**：短信发出后 7 天内发生的点击或付费，才归该短信；窗口按实际发送日算。
2. **未点击不计入**：窗口内没点过该短信、之后付费的，不计入该短信的点击与增量转化，但计入全链路总支付。
3. **多条短信**：同一用户点了两条短信，归到最后点击的那条。
4. **用户去重**：同一用户在同一指标只计一次。
5. **自然转化**：没点任何短信直接付费的，计入全链路支付，不计入任何短信增量转化。
6. **队列分组**：以注册日为第 0 天，观察第 0~9 天。
7. **未完结标注**：最新一周数据未满窗口，需标注可能偏低。
8. **计费口径**：成本按计费条数算（超 70 字计 2 条），不是发送条数。
