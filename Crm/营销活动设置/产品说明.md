# 优惠活动设置（人群版）产品说明

> 依据文件：`Crm\营销活动设置\优惠活动设置-人群版.html`（当前实际实现）
> 面向对象：后端开发
> 说明：本文仅描述本次改造的**新增内容、联动操作与校验逻辑**，不含原有页面基础功能、提交格式、数据结构与界面样式细节。

## 1. 本次新增

- **固定六类人群启用配置（公共区块）**
  - 新增 `lq` 临期客户 / `fk` 付费客户 / `xk` 新客户 / `mf` 免费用户 / `dq` 地区会员 / `mfa` 全部免费会员 六类固定人群，页面提供统一的启用勾选配置区，两种活动类型共用。
  - 人群排序靠上的优先级高于下方，匹配时优先命中上方人群。
  - 人群启用状态是优惠券绑定、奖池配置与保存校验的公共前提。

- **优惠券绑定按人群分组平铺**
  - 每类人群独立一张绑定表，逐一配置该人群可发放的优惠券，各人群配置互不干扰。
  - 每类人群独立支持「添加」：弹出券选择弹层，勾选后确定回填到该人群绑定表。
  - 同一人群内按券 ID 去重，同一张券不会重复绑定；已绑定的券在弹层中不可重复选择。

- **报名结果文案 / 奖池按人群一一对应平铺**
  - 每类人群独立一张奖池表，配置该人群报名后的文案与概率，各人群独立管理。

- **预置假优惠券数据仅为原型演示**
  - 页面预置的优惠券（初始绑定数据与弹层候选池）均为原型演示用假数据，后端须以真实券库为准，返回同构数据即可复用现有绑定与回填逻辑。

- **地区会员 dq 人群**
  - 新增 `dq` 地区会员 人群及对应配置区（启用勾选、优惠券绑定块、奖池块），匹配规则由后端定义，原型仅提供配置区与演示假数据。

## 2. 联动操作

- **活动类型切换**：选择「优惠券」类型时展示优惠券绑定配置区；选择「仅报名」类型时展示报名结果文案（奖池）配置区。
- **人群启用 / 停用勾选**：
  - 停用某人群 → 该人群整行置灰，其对应的优惠券绑定块、奖池块整体隐藏；
  - 重新启用 → 恢复显示。
  - 页面始终要求至少保留 1 个人群处于启用状态（保存时校验）。

## 3. 校验逻辑（保存时逐项拦截）

- **基础必填**：活动名称、活动状态、开始时间、截止时间、权重等原有必填项未填写时提示。
- **人群启用**：至少启用 1 个人群，否则拦截提示。
- **优惠券类型**：每个启用人群至少绑定 1 张券，未绑定则拦截并提示对应人群。
- **仅报名类型**：对每个启用人群的奖池独立校验，任一不通过即拦截：
  1. 该人群奖池至少 1 行；
  2. 文案（奖品名称）不可为空；
  3. 概率必须大于 0；
  4. 该人群概率合计必须等于 100%。
- 校验提示均带人群名称，便于定位到具体人群。
