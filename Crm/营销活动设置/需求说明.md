# 优惠活动设置-人群版 需求说明

## 1. 页面用途

活动创建/编辑页（原型，单文件可双击打开）。支持两类活动：**优惠券**（给人群绑优惠券）与**仅报名**（给人群配奖池）。四类固定人群各自独立配置，人群可启用/停用。

- 主文件：`优惠活动设置-人群版.html`（css 已全部内联，无外部 css 依赖；js 依赖本地 jQuery 1.8.2 / layer / laydate）
- 提交目标：后端 `http://crm.caizhaowang.com:8086/bid/huodong/Edit.aspx?id=28`（原型中为假提交，`#Button1` 触发）

## 2. 活动基本信息

| 字段 | 控件 | 必填/规则 |
|---|---|---|
| 活动名称 `tam_name` | text | 编辑态（id>0 且非复制）disabled |
| 活动标题 `tam_title` | text | 必填，≤12 字 |
| 活动时间 `tam_stime`/`tam_etime` | laydate datetime | 必填 |
| 活动状态 `tam_status` | radio 0开启/1关闭 | 必填 |
| 权重 `tam_weight` | text，仅数字 | 必填 |
| 活动类型 `tam_type` | radio 1优惠券 / 2仅报名 | 决定下方显示区块 |

## 3. 活动类型切换

- `chgConType()`：读取 `tam_type` 选中值，`.switchType` 全部隐藏，`.swTp{值}` 显示。
  - 优惠券（value=1）→ 显示 `swTp1` 优惠券绑定区
  - 仅报名（value=2）→ 显示 `swTp2` 活动人群 + 报名结果文案/奖池区
- `tam_type` change 时重新调用 `chgConType()`；页面初始化时调用一次。

## 4. 四类固定人群

key 与定义（`#crowdTable` 行 `data-crowd`）：

| key | 名称 | 匹配规则说明 |
|---|---|---|
| lq | 临期客户 | 会员/套餐即将到期 |
| fk | 付费客户 | 已产生付费 |
| xk | 新客户 | 注册 ≤ 7 天 且 未付费 |
| mf | 免费用户 | 注册 > 7 天 且 未付费 |

- 每行首列 `.crowdCheck` checkbox 控制启用/停用。
- `refreshCrowdState()` 联动：未启用 → 行加 `crowd-disabled` 整行置灰；对应 Tab（`#crowdTabs` / `#yhqCrowdTabs`）与奖池表/优惠券表/添加按钮隐藏。
- `fixActiveTab()`：当前激活 Tab 被隐藏时自动切到本组第一个可见 Tab（否则隐藏全部表）。
- 校验规则：至少启用 1 个人群才能保存（`checkCrowd()`）。
- 人群显示名通过 `getCrowdName(key)` 从 `#crowdTable` 取。

## 5. 优惠券绑定区（仅优惠券类型）

独立 Tab 组 `#yhqCrowdTabs`（lq/fk/xk/mf），切换由 `switchYhqTab(key)` 控制对应 `table.yhqTable` 与 `+` 按钮显隐。

### 5.1 数据结构 yhqData

```js
yhqData = { lq: [...], fk: [...], xk: [...], mf: [...] }  // 每项为 JSON 字符串
// 字段（renderYhqTable 使用）：
{"id": 101, "name": "临期续费券", "limitDes": "满1000减100元", "indate": "2026-09-29至2026-10-11"}
```

| 字段 | 含义 |
|---|---|
| id | 优惠券 ID（渲染进 `<td class="index" yhqid="...">`，保存时收集） |
| name | 优惠券名称 |
| limitDes | 金额、类型描述 |
| indate | 使用期限 |

- 页面已预置假数据：lq 3 张、fk 2 张、xk 3 张、mf 2 张；加载时对 4 个人群各调用一次 `renderYhqTable(key)`，保证绑定表非空、保存校验可通过。

### 5.2 候选券池 yhqPool

```js
yhqPool = { lq: [{id, name, limitDes, indate}, ...], fk: [...], xk: [...], mf: [...] }  // 对象数组，各人群独立
```
每人群 3~5 张候选券（含已预置券 + 可追加券），作为弹窗数据源。

### 5.3 本地选择弹窗（替代后端 YhqSelector.aspx）

- `addYhq(crowdKey)`：`layer.open({type:1})` 页面内弹层，标题"选择优惠券 - {人群名}"，弹层顶部显示"当前人群：{人群名}"。
- 券列表按当前人群（`yhqPool[crowdKey]`）渲染，checkbox 勾选；已在 `yhqData` 中的券 `checked + disabled`。
- `confirmYhqSelect()`：收集 `$(".yhqSelItem:checked")`，按 id 去重后 `JSON.stringify` 追加进 `yhqData[currentYhqCrowd]`，调 `renderYhqTable(key)` 回填绑定表，`layer.closeAll()`。
- 取消：`layer.closeAll()`。

### 5.4 保存

优惠券类型校验（`checkConType` 内）：遍历已启用人群，`yhqData[key]` 非空（否则 `{人群名}请选择优惠券`），收集所有券 id：

```js
$("#yhqData").val(ids.join(','))   // 提交格式：逗号分隔 id 串
```

## 6. 奖池配置区（仅报名类型）

- 独立 Tab 组 `#crowdTabs`（lq/fk/xk/mf），与优惠券 Tab 组各自独立、不合并。
- 选中 Tab 后，`#prizeCrowdTitle` 显示"当前人群：{人群名}"标题，下方仅显示该人群 `table.prizeTable`；`switchCrowdTab(key)` 切换时标题同步更新。
- 每个 `prizeTable` 内每行：`input.prizeName`（文案/奖品名称）+ `input.prizeProb`（概率 %）。
- `addPrize(crowdKey)` 追加行；`removePrize(this)` 删行；`loadPrizeIndex()` 各人群池独立重排序号。

### 6.1 校验（checkPrize）

按已启用人群各自独立校验：

1. 奖品行数 > 0（`{人群名}请填写奖品信息`）
2. 奖品名称非空（`{人群名}奖品名称不可为空`）
3. 概率 > 0（`{人群名}奖品概率不可为空`）
4. 概率合计 == 100（`{人群名}人群奖品总概率必须为100%`）

通过后组装提交数据：

```js
prizeArr = [{ crowd, crowdName, name, prob }, ...]
$("#prizeData").val(JSON.stringify(allArr))   // 提交格式：JSON 数组
```

## 7. 保存流程与提交格式

`next()` 校验顺序：活动名称 → 活动状态 → 开始时间 → 截止时间 → 权重 → `checkConType()`：

| 活动类型 | 校验 | 提交 |
|---|---|---|
| 优惠券(1) | 至少启用1人群 + 各启用人群绑定表非空 | `#yhqData` = id 逗号串 |
| 仅报名(2) | `checkCrowd()` + `checkPrize()` | `#prizeData` = JSON 数组 |

校验通过且 `id>0 && copyid<=0` 时 `layer.confirm` 二次确认，随后 `$("#Button1").click()` 提交表单。隐藏字段：`#yhqData`、`#prizeData`。

| `checkConType()` | 按活动类型整体校验并写隐藏字段 |
| `checkCrowd()` | 至少启用一个人群 |
| `checkPrize()` | 各启用人群奖池校验 + 组装 prizeData |
| `sum(array, prop)` | 对象数组数值属性求和 |
| `getEnabledCrowds()` / `getCrowdName(key)` | 启用人群 key 列表 / 人群显示名 |
| `addYhq(crowdKey)` | 打开本地假券选择弹窗 |
| `confirmYhqSelect()` | 弹窗确定，回填 yhqData 并渲染 |
| `renderYhqTable(key)` | 渲染指定人群优惠券绑定表 |
| `addPrize/removePrize/loadPrizeIndex` | 奖池行增删与序号重排 |
| `switchCrowdTab(key)` / `switchYhqTab(key)` | 奖池/优惠券独立 Tab 切换 |
| `refreshCrowdState()` / `fixActiveTab()` | 人群启用停用联动与激活 Tab 修复 |
