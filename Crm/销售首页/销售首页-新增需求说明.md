# 销售首页 · 新增需求说明

> 页面：`Crm/销售首页/销售首页.html`
> 说明：本文档整理本批次在销售首页上新增/调整的需求，供对接与开发使用。

---

## 0. 通用约定

### 0.1 权限

| 项 | 约定 |
|---|---|
| 使用角色 | **默认全部为「销售」**——登录角色为销售即可看到本批全部改动 |
| 数据可见范围 | 一律为**本人数据**（自己的业绩、排名、外呼、客户库、回访安排），不涉及查看他人 |
| 特殊权限 | 本批需求**无**额外权限点；如后续要限制（如仅主管可见业绩排名），单独提需求 |

### 0.2 数据来源

- 来源标注为 **「空」** = 尚未对接真实接口，页面当前为**演示占位数据**，联调时按接口回填。
- 演示基准日期：2026-10-19（周一）。

## 1. 需求清单

### 需求 1：业绩指标移至「我的客户情况」标题行

- **位置**：part1「我的客户情况」标题行右侧（原导航右上角的业绩速览卡**已移除**，仅此处展示，不重复）。
- **内容**（三项横排一行、右对齐、无底色）：
  1. 当前业绩（橙色数值）
  2. 我的排名（蓝色数值）
  3. 与相邻名次的差距（红/绿/灰数值）
- **逻辑**：
  - 差距规则：第 6 名及以后显示「距上一名 · 第 N 名 差 X」（红）；前五名（含第 1 名）显示「距下一名 · 第 N 名 领先 X」（绿）；第 1 名无下一名显示灰态。
  - 页面内「演示前五视角 / 第 50 名视角」切换按钮会同步刷新这三项（元素 id：`ny_money` / `ny_rank` / `ny_gap` / `ny_gap_label`，切换脚本保留）。
  - 实际场景由后端按当前用户名次驱动，前端按上述规则渲染。
- **权限**：销售（默认），仅本人业绩/排名。
- **数据来源**：**空**（业绩 + 月度排名接口）。演示值：`8,200` / `第50名` / `差 300`。

### 需求 2：销售个人信息卡新增外呼三项

- **位置**：part1 左卡（销售个人信息），「今日捡回 / 今日分发 / 转化C级以上」下方。
- **内容**（一行横排三项）：外呼次数、接通量、总时长。
- **逻辑**：
  - 与上方今日数据用**横向虚线分割**：虚线横跨卡片全宽，位于照片底边下方 18px（**不与照片重叠**），虚线与下方文字间距 10px。
  - 口径：当日（今天）累计外呼统计。
- **权限**：销售（默认），仅本人外呼数据。
- **数据来源**：**空**（外呼/话单系统）。演示值：`86` / `32` / `2时36分`。

### 需求 3：客户库信息区位置调换 + 环形图放大

- **位置**：part1 左卡右侧客户库信息区（quota 区）。
- **逻辑**：
  - 上下顺序调换：**容量使用率环形图在上**（含「容量使用率」图例），**客户库总数、总容量两行在下**。
  - 环形图由 76×76 放大为 **96×96**，中间百分比字号 17px → 21px（绘制按画布尺寸自适应）。
  - 左右区域之间竖向虚线**贯穿整卡高度**（随卡片等高拉伸），清晰分区。
- **权限**：销售（默认），仅本人客户库。
- **数据来源**：**空**（客户库容量统计）。演示值：`720` / `550` / `21%`。

### 需求 4：销售照片占位尺寸

- **位置**：part1 左卡一寸照占位。
- **逻辑**：占位框调整为 **117 × 167**（保持人像图标 + 「一寸照片」标签样式）。
- **权限**：销售（默认）。
- **数据来源**：不涉及（静态占位，后续接真实照片上传另提）。

### 需求 5：左侧回访表改名与文案整理

- **位置**：part2 左表。
- **文案调整**：
  - 标题：`库中联系人回访日程：` → **`库中客户回访日程：`**
  - 副标题：`按客户等级分类日内` → **`按客户等级统计每日回访数量`**（原语序不通，已整理）
- **逻辑**：表格口径不变——今天及以后 7 天 × 客户等级（AA~E + 合计）的每日回访数量；「下一周 / 上一周」双周翻页；今天/明天行标记、周末行暖橙特殊显示。
- **权限**：销售（默认），仅**本人客户库**（库中）数据。
- **数据来源**：**空**（回访安排接口）。演示值：7 天分等级数量。

### 需求 6：两张回访表等级列去彩（黑白统一）

- **位置**：part2 左表（库中客户回访日程）+ 右表（提交B级客户回访日程），两表一致。
- **逻辑**：
  - 等级列表头（AA/A/B/C/D/E）统一**灰底灰字**（`#8d96a5`），不再红/橙/绿彩底。
  - 等级数量统一**黑色**（`#333`，不加粗），0 值灰色。
  - 保留的色彩仅：合计黑体、今天行浅蓝、周末行暖橙、标题/按钮品牌蓝——页面色彩收敛。
- **权限**：销售（默认）。
- **数据来源**：不涉及（纯样式）。

### 需求 7：版式稳定（窄窗口不跳变）

- **逻辑**：大屏版式恒真（media 恒真生效）——`.sales_center` 定宽 1200，任意窗口宽度版式一致；窗口 < 1200 时只出现横向滚动条，**元素不移动**（修复 1199px 时整体移位问题）。
- **权限**：不涉及（全局展示）。
- **数据来源**：不涉及。

5. 两表等级列均为灰表头黑数字；页面无 AA/A/B 彩色残留。
6. 窗口宽度从 1200 缩到 1199 页面不发生任何移位。
