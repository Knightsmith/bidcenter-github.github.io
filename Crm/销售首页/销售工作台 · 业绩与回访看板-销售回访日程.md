# 销售首页 · 新增需求说明

> 页面文件：`Crm/销售首页/销售首页.html`
> 本文说明销售首页本批新增需求的位置、展示逻辑、字体颜色字号、权限与数据来源。

---

## 0. 通用约定

| 项 | 约定 |
|---|---|
| 使用角色 | **默认全部为「销售」**——登录角色为销售即可看到本批全部内容 |
| 数据范围 | 一律为**本人数据**（本人业绩、排名、外呼、客户库、回访安排），无跨人查看，无额外权限点 |
| 数据来源标注「空」 | 尚未对接真实接口，页面当前为**演示占位数据**，联调时按接口回填 |
| 演示基准日期 | 2026-10-19（周一） |

## 1. 需求清单

### 需求 1：业绩指标展示于「我的客户情况」标题行

**位置**：part1「我的客户情况」标题行右侧，三项横排一行、右对齐、无底色。

**内容与样式**：

| 元素 | 字号 | 颜色 |
|---|---|---|
| 指标标签（当前业绩 / 我的排名 / 距上一名 / 下一名） | 12px | `#8a97a8` |
| 指标数值（通用） | 17px 加粗 | `#333` |
| 当前业绩数值 | 17px 加粗 | `#ff6600`（橙） |
| 我的排名数值 | 17px 加粗 | `#157fcc`（蓝） |
| 追赶数值（差 X · 即将追上） | 17px 加粗 | `#1fa35a`（绿） |
| 领先数值（暂时领先 X） | 17px 加粗 | `#1fa35a`（绿） |
| 项与项之间竖分隔线 | 1px 宽、高 16px | `#d5dbe3` |

- 标签与数值间距 6px；每项左右内边距 14px。

**展示逻辑**：

1. 三项依次为：当前业绩、我的排名、与相邻名次的差距。
2. 差距规则（追赶与领先均为绿色正向激励，无红色/灰色态）：第 2 名及以后显示标签「距上一名」+ 数值「差 X · 即将追上」；第 1 名显示标签「下一名」+ 数值「暂时领先 X」。标签不写具体名次（"上一名/下一名"已唯一确定目标）。
3. 页面 part3「月度业绩排名」区有「演示前五视角 / 演示第50名视角」切换按钮，切换时同步刷新标题行三项（元素 id：`ny_money` / `ny_rank` / `ny_gap` / `ny_gap_label`）；实际场景由后端按当前用户名次驱动。

**权限**：销售（默认），仅本人业绩与排名。

**数据来源**：**空**（业绩 + 月度排名接口）。演示值：`8,200` / `第50名` / `差 300 · 即将追上`。

**位置**：part1 左卡（销售个人信息），今日数据下方，横跨卡片全宽。

**展示逻辑**：口径为当日（今天）累计外呼统计，三项一行展示。

**权限**：销售（默认），仅本人外呼数据。

**数据来源**：**空**（外呼 / 话单系统）。演示值：`86` / `32` / `2时36分`。

## 4. 验收要点

1. 业绩三项位于「我的客户情况」标题行右端：当前业绩（橙 `#ff6600`）、我的排名（蓝 `#157fcc`）、差距（绿 `#1fa35a`，追赶态「差 X · 即将追上」/ 第1名「暂时领先 X」），无底色、竖线分隔。
2. 左卡底部外呼三项一行，上方虚线横跨全宽且位于照片底边下方、不压照片。
3. 客户库信息区：96px 环形图在上，客户库总数 / 总容量两行在下，竖虚线贯穿分区。
4. 照片占位 117 × 167。
5. 左表标题为「库中客户回访日程：按客户等级统计每日回访数量」。
6. 两表等级列均为灰表头（`#8d96a5` / 底 `#f4f6f9`）黑数字，无彩色残留。
7. 窗口宽度从 1200 缩到 1199 页面不发生任何位移，仅出现横向滚动条。
