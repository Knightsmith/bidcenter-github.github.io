# 销售首页.html 重构说明

> 基于 2026-10-19 版本（约 2857 行）整理，供重构参考。

## 1. 页面概述

- **性质**：销售 CRM 工作台首页的**静态演示页**，单文件自包含（HTML + 内联 CSS + 内联 JS 全部在一个文件里）。
- **依赖**：内联 jQuery 1.8.3（约 530 行处）；无其他外部资源（图标/头像均为 CSS/SVG 占位）。
- **编码**：UTF-8 **带 BOM**（保存时需保留，否则页面可能乱码）。
- **交互占位**：全局拦截所有 `<a>` 链接（仅 `e.preventDefault()`，不阻止 jQuery click），点击弹 `alert("演示页面…")`；真实链接均指向 `crm.caizhaowang.com:8086`（重构后按需替换）。

## 3. 布局与样式体系

### 3.1 栅格与等高

- **两栏栅格**：`.sales_content .fl/.fr { width: calc(50% - 7px); }`，`.fr { margin-left: 14px; }`（中间 14px）。
- **断点**：基础（≥1000px）与 `min-width: 1200px`（`.sales_center` 定宽 1200，`.sales_content` padding 变 20px 0）。
- **等高机制**：
  - `.sales_part1 { display:flex; flex-wrap:wrap; align-items:stretch; }` — 同行两栏盒高自动对齐。
  - **左卡动态等高 JS `alignZlHeight()`**（页尾）：左卡高度 = `max(自身内容高, 右侧末张小卡视觉底 − 右容器顶)`，随 `resize` 重算。*注意：右侧容器盒底比小卡视觉底多 14px（末 li 下 margin），必须用 li 的 getBoundingClientRect 取视觉底。*
  - part2/4 用 flex 容器 + 子卡 `flex:1 1 auto` 拉伸。
- **垂直节奏**：板块间距 = `.sales_content > .sales_part2/4/6 { margin-top: 16px }`（1200 断点 22px）；板块标题与卡片间 = `.sales_part_zl { margin-top: 14px }`。

### 3.2 卡片规范（所有白卡统一）

```css
border-radius: 8px;  padding: 16px 20px 18px;   /* 1200 断点: 16px 24px 20px */
border: 1px solid #edf1f6;
box-shadow: 0 2px 8px rgba(31,56,88,0.06);
```

- **标题**：`.sales_part_tit` 蓝色 4px 左边框 + 加粗（16px / 1200 断点 18px）。
- **品牌色**：蓝 `#3497da`、橙 `#ff6600`。
- **等级色**（`lv_table`）：AA `#e8443a`、A `#ff6600`、B `#2fa36b`、C/D/E 表头灰底、数量黑/0 值灰（`td.is-zero`）。

### 3.3 表格规范（等级表 / 榜单表通用）

- `table-layout: fixed` + **colgroup 百分比列宽**（固定表头表 + 滚动体表**共用同一 colgroup**，改列宽须两表同步）。
- 单元格统一 `overflow:hidden; text-overflow:ellipsis; white-space:nowrap; box-sizing:border-box`。
- 日期列三段式：`<b>10-19</b><i>周一</i><em>今天</em>`；今日行浅蓝高亮、明日灰徽章、周末行 `is-weekend` 暖底 `#fffaf3`。

### 3.4 part1 详情卡内部（重点改造区）

```
sales_part_zl fl  ← 高度由 JS 锁定，justify-content:center
└─ sales_card_row（flex 左右分栏）
   ├─ 左 sales_part_cont：一寸照占位 id_photo + 姓名「北京-销售一部-罗屿」
   │    + 捡回/分发/转化（内部全 float，靠 ::after 清浮动，勿删）
   └─ 右 sales_quota（136px，虚线左边框）：指标两行（12/16px 小字号）
        + 76px canvas 圆环 pageView(0.21)
```

- 右栏 `.sales_customer`：6 个 li 统计卡（基础 153×96 / 1200 断点 189×110），浮动布局**每行数量随视口变化**（影响右栏视觉高度，等高 JS 已兼容）。

## 5. 演示数据口径

- 演示日期 **2026-10-19（周一）**；回访表 7 天（10-19~10-25 + 第二周 10-26~11-01）、提交表 5 天（10-15~10-19），**行内合计数字均已核算自洽**（重构取数时保持勾稽）。
- 客户分布：AA0 A0 B1 C38 D658 E22 S0 N1 K0（合计 720）。
- ⚠️ **已知不勾稽**：客户详情「客户库总数 720 / 总容量 550 / 环 21%」三者无换算关系（550÷720≈76%）。重构时建议确定口径：① 总容量 720、总数 550、环 76%；或 ② 保持数字、环改为真实含义。

## 6. 重构注意事项

1. **浮动与 flex 混用**：`.sales_part_cont` 内全 float 靠 `::after` 清；`.sales_customer` 的 li 是 float（ul 作为 flex item 自带 BFC 才撑高，改动容器 display 会破坏等高）。
2. **CSS 死值**（被主规则覆盖的历史遗留，重构可清理）：`.sales_part4 {margin-top:15px}`、`.sales_part6 {17px}`、media 内 `.sales_part2 {12px}`、`.sales_part4 {24px}`、`.sales_part6 {20px}`、`.part2_rwl` 系列（HTML 中无实例）。
3. **共用类选择器**：`sales_part_zl` 被 4 处使用，**part1 专属规则必须限定** `.sales_part1 > .sales_part_zl`（height 206/234 是 JS 未执行前的兜底初值）。
4. **双表结构**：固定表头 + 滚动体是两张 table，列宽/等级色等样式改动需两边同步。
5. **canvas 环**：`pageView` 曾有底部二次调用覆盖（已统一 0.21），重构时确保单实例单调用。
6. **BOM**：保存保持 UTF-8 with BOM。
7. **验证手段**：可用无头 Edge 实测布局——
   ```
   & "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu --window-size=1400,900 --dump-dom "file:///…销售首页.html"
   ```
   或 `--screenshot=xx.png` 截图；JS 语法用 node 校验所有 `<script>` 块。
