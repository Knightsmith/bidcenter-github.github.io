## 二、API 结构事实（推断，发布前需验证）

- 安装命令：`npm install -g caizhao-token-skill`；`npx -y @caizhao/token-mcp`；`npm install -g caizhao-token-cli`；`cz init`
- 所有接口 POST（账户类 GET），路径 `/api_v2/{tool_name}`
- Base URL：https://api.caizhao-token.com（域名未验证，无法解析）
- 认证：X-API-Key Header；响应统一 `{success, data, error, meta{cost_units, tool}}`
- 限流：5 次/秒、2000 次/小时
- 关键词：整体 ≤100 字（含标点）；排除词整体 ≤50 字（含标点）；page 默认 1 最大 50；page_size 默认 20 最大 40；search_company 最多返回 200 条
- 关键词写法：多个词英文逗号 `,` 分隔（中文逗号/空格会替换为英文逗号）；强关联用 `+`（如 `服务器+医疗`）；keywords 为 OR，keyword_groups 为 AND
- match_modes：sm / title / fulltext（关键词搜索范围）/ fulltext（排除词搜索范围）/ caller / winner / tender / winner_tender / agent
- 充值档位：¥1000=10000 积分、¥3000=35000 积分、¥3500=60000 积分
- 充值链接：user.bidcenter.com.cn/v2023/#/accountCenter/dataBalance（可访问，属采招网；真实域名体系为 bidcenter.com.cn 系列）
- 待验证域名：api.caizhao-token.com、www.bidcente.com 均无法解析
