简介

采招词元是面向招投标领域的 AI 数据平台，提供全国招标、中标公告的智能查询与分析能力。通过 Skill / MCP / CLI / API 四种形态接入，让 AI Agent 自动完成标讯检索、市场分析、对手与业主洞察等任务，把招投标数据装进你的 AI。

01

获取 API Key

注册账号后在个人中心创建 API Key，新用户赠送 200 积分。

02

选择接入形态

Skill / MCP / CLI / API 四种方式任选，共用同一 API Key 与积分。

03

开始使用

在 AI Agent 或终端中直接调用，30 秒完成接入。

市场分析行业与区域趋势洞察

安装 #

采招词元提供 Skill、MCP、CLI 三种本地接入形态，按需选择一种即可；API 无需安装，直接调用接口。所有形态共用同一 API Key 与积分。

环境要求

  • Node.js 16 或更高版本（Skill / MCP / CLI 均依赖）
  • npm 包管理器
  • 已获取采招词元 API Key（新用户注册赠送 200 积分）

方式一：安装 Skill（推荐）

安装后 AI Agent 可自动识别招投标需求并调用查询能力，即装即用。

npm install -g caizhao-token-skill

方式二：安装 MCP

通过 Model Context Protocol 接入，让 AI 助手直接调用招投标数据查询能力。

npx -y @caizhao/token-mcp

方式三：安装 CLI

命令行工具，在终端中快速查询和分析招投标数据。

npm install -g caizhao-token-cli

初始化与验证

# 初始化配置（生成含全部注释的默认配置文件）
cz init

# 查看版本，验证安装成功
cz --version

# 测试查询：搜索最近 30 天广东省的信息安全类招标公告
cz search --keywords '["信息安全"]' --provinces '["广东"]' --begin-date "2026-08-01"

升级

# 升级 Skill
npm update -g caizhao-token-skill

# 升级 CLI
npm update -g caizhao-token-cli

# 升级 MCP
npx -y @caizhao/token-mcp@latest
i
提示：四种接入形态共用同一 API Key 与积分，调用同一能力扣同样的积分，与接入方式无关。

配置概览 #

所有接入形态（Skill / MCP / CLI / API）共享同一套配置体系。配置主要解决四类问题：

  • 凭证与端点：API Key、Base URL，安全地通过环境变量或密钥文件引用；
  • 模型与触发：默认模型、轻量任务模型，以及 Skill 的自动触发开关；
  • 服务与行为：MCP 服务器、CLI 输出格式、订阅通知渠道与规则；
  • 安全与边界：哪些操作需要确认、哪些指令文件会被注入到 AI Agent。
i
快速上手：安装 CLI 后执行 cz init 会在 ~/.config/caizhao-token/config.json 生成一份带全部注释的默认配置文件，直接编辑即可完成接入。

配置示例 #

下面是一份完整的配置文件示例，包含采招词元常用的全部配置键。将以下内容保存为 config.json 并放入配置位置即可生效：

{
  "$schema": "https://caizhao-token.com/schema/config.json",
  "apiKey": "{env:CZ_TOKEN}",
  "baseUrl": "https://api.caizhao-token.com",
  "model": "deepseek-chat",
  "small_model": "deepseek-lite",

  "skill": {
    "enabled": true,
    "autoTrigger": true,
    "description": "招投标数据查询：搜索标讯、分析市场、追踪对手与业主",
    "skillPath": "./skills/caizhao-token/SKILL.md"
  },

  "mcp": {
    "servers": {
      "caizhao": {
        "url": "https://mcp.caizhao-token.com",
        "enabled": true
      }
    }
  },

  "cli": {
    "language": "zh-CN",
    "outputFormat": "table",
    "subscriptionFile": "~/.config/caizhao-token/subscriptions.json"
  },

  "notify": {
    "channel": "webhook",
    "webhookUrl": "https://example.com/hook",
    "dailyTime": "09:00",
    "keywords": ["数据中心", "智慧城市", "医疗信息化"]
  },

  "permission": {
    "requireConfirm": ["query", "export"]
  },

  "instructions": ["docs/caizhao-guidelines.md"]
}

上面的示例覆盖了：凭证（apiKey / baseUrl）、模型（model / small_model）、Skill 触发（skill）、MCP 服务（mcp）、CLI 行为（cli）、订阅通知（notify）、权限控制（permission）以及指令注入（instructions）。每个配置项详见「配置项详解」。

配置位置与优先级 #

你可以将配置放置在不同的位置，它们具有不同的优先级。配置文件是合并的，而不是被替换：来自以下配置位置的设置会被合并，后面的源仅在键冲突时覆盖前面的源，所有非冲突设置都会被保留。

例如，如果全局配置设置了 model: "deepseek-chat"，而项目配置设置了 notify: { "dailyTime": "08:30" }，最终配置将同时包含这两项。

加载顺序

配置源按以下顺序加载（后面的源覆盖前面的源）：

  1. 远程配置（组织默认值，通过 .well-known/caizhao-token 端点自动下发）
  2. 全局配置（~/.config/caizhao-token/config.json，用户偏好）
  3. 自定义配置（CZ_CONFIG 环境变量指定的文件路径，自定义覆盖）
  4. 项目配置（项目目录下的 .caizhaorc.json，项目特定设置）

这意味着：项目配置可以覆盖全局默认值，全局配置可以覆盖远程组织默认值。各位置配置合并示例：

// 1. 远程配置（组织默认值，由管理员在控制台维护，自动下发）
{
  "model": "deepseek-chat",
  "skill": { "autoTrigger": true }
}

// 2. 全局配置 ~/.config/caizhao-token/config.json
{
  "apiKey": "{env:CZ_TOKEN}",
  "model": "deepseek-reasoner"
}

// 3. 自定义配置（CZ_CONFIG 指向的文件）
{
  "notify": { "channel": "webhook" }
}

// 4. 项目配置 ./.caizhaorc.json
{
  "model": "qwen-max",
  "notify": { "dailyTime": "08:30" }
}

上例最终生效的配置：apiKey 来自全局配置，model 被项目配置覆盖为 qwen-max，skill.autoTrigger 保留远程默认值 true，notify 来自全局与项目配置的合并（channel=webhook + dailyTime=08:30）。

组织远程配置

组织可以通过 .well-known/caizhao-token 端点提供默认配置。当你使用支持该功能的账号进行身份验证时，采招词元会自动获取此配置。远程配置最先加载，作为基础层，所有其他配置源都可以覆盖这些默认值。

例如，如果组织默认禁用了某个 MCP 服务器：

{
  "mcp": {
    "servers": {
      "jira": { "url": "https://jira.example.com/mcp", "enabled": false }
    }
  }
}

你可以在本地配置中启用它：

{
  "mcp": {
    "servers": {
      "jira": { "enabled": true }
    }
  }
}

全局配置

将采招词元的全局配置放在 ~/.config/caizhao-token/config.json。使用全局配置来设置用户级别的偏好，例如默认模型、API Key、订阅通知等。全局配置覆盖远程组织默认值。

// ~/.config/caizhao-token/config.json
{
  "apiKey": "{env:CZ_TOKEN}",
  "model": "deepseek-chat",
  "notify": { "channel": "webhook", "dailyTime": "09:00" }
}

项目配置

在项目根目录添加 .caizhaorc.json。项目配置在标准配置文件中具有最高优先级——它会覆盖全局配置和远程配置。该文件可以安全地提交到 Git 中，使用与全局配置相同的 Schema。注意：.caizhaorc.json 内应避免写入密钥，如需使用 API Key 请用 {env:CZ_TOKEN} 引用环境变量。

// ./.caizhaorc.json
{
  "model": "qwen-max",
  "skill": { "autoTrigger": false },
  "cli": { "outputFormat": "json" }
}

Schema 与编辑器支持

配置文件使用定义在 https://caizhao-token.com/schema/config.json 的 JSON Schema。你的编辑器应该能够基于该 Schema 对配置进行校验和自动补全（VS Code 支持 JSONC 注释）。

配置项详解 #

以下为各配置项的使用说明与代码示例。所有配置项均为可选，未配置时使用产品默认值。

apiKey
API 密钥，用于身份认证与用量计费。建议通过环境变量引用，避免明文写入配置文件。配置后所有接入形态（Skill / MCP / CLI / API）共用同一密钥。
{
  "apiKey": "{env:CZ_TOKEN}",
  "baseUrl": "https://api.caizhao-token.com"
}
model / small_model
model 为默认模型，用于招投标分析、报告生成等主任务；small_model 为轻量任务模型，用于标题生成、意图判断等轻量级任务。默认情况下，采招词元会优先使用更轻量的模型处理轻量任务，否则回退到主模型。
{
  "model": "deepseek-chat",
  "small_model": "deepseek-lite"
}
skill
Skill 配置：enabled 控制是否启用采招词元 Skill；autoTrigger 控制 AI Agent 是否根据对话内容自动触发（description 触发开关，默认开启）；description 是触发开关本身，AI Agent 平时只读取这段描述来判断是否需要读取 SKILL.md 全文；skillPath 指定 SKILL.md 文件路径。
{
  "skill": {
    "enabled": true,
    "autoTrigger": true,
    "description": "招投标数据查询：搜索标讯、分析市场、追踪对手与业主",
    "skillPath": "./skills/caizhao-token/SKILL.md"
  }
}
i
触发机制：AI Agent 平时只看 description（几十个字）判断是否需要触发，只有判断「需要用这个 Skill」时才读取 skillPath 指定的 SKILL.md 全文。因此 description 是触发开关，正文是操作手册。
mcp
MCP 服务器配置：通过 servers 声明要连接的 MCP 服务器，每个服务器包含 name（服务器名）、url（SSE/HTTP 端点地址）、enabled（是否启用）。
{
  "mcp": {
    "servers": {
      "caizhao": {
        "name": "caizhao",
        "url": "https://mcp.caizhao-token.com",
        "enabled": true
      }
    }
  }
}
cli
CLI 行为配置：language 默认输出语言（zh-CN / en）；outputFormat 输出格式（table / json / csv）；subscriptionFile 订阅规则文件路径，用于 cz sub 命令持久化订阅规则。
{
  "cli": {
    "language": "zh-CN",
    "outputFormat": "table",
    "subscriptionFile": "~/.config/caizhao-token/subscriptions.json"
  }
}
notify
订阅通知配置：channel 推送渠道（webhook / email / dingtalk / wecom）；webhookUrl 回调地址；dailyTime 每日订阅汇总推送时间；keywords 关键词规则，命中关键词的新标讯将被推送。支持与 Skill 定时任务、CLI cz sub 组合使用。
{
  "notify": {
    "channel": "webhook",
    "webhookUrl": "https://example.com/hook",
    "dailyTime": "09:00",
    "keywords": ["数据中心", "智慧城市", "医疗信息化"]
  }
}
permission
权限控制：指定哪些操作需要用户确认后才可执行。默认采招词元允许所有查询类操作自动执行；requireConfirm 数组中的操作在触发前会请求用户确认，例如 query（数据查询）、export（导出文件）、subscribe（创建订阅）。
{
  "permission": {
    "requireConfirm": ["export", "subscribe"]
  }
}
instructions
指令文件引用：配置额外的指令文件路径或 glob 模式，这些文件的内容会被注入到 AI Agent 的上下文，用于约束分析口径、输出规范等。支持相对路径（相对于配置文件所在目录）与 ~ 开头的主目录路径。
{
  "instructions": [
    "docs/caizhao-guidelines.md",
    "docs/analysis-rules/*.md"
  ]
}

环境变量 #

除配置文件外，采招词元支持通过环境变量覆盖关键配置。环境变量在配置合并中的优先级低于项目配置，适用于容器化部署、CI/CD 等无法直接编辑配置文件的场景。

环境变量说明示例
CZ_TOKENAPI 密钥，最常用的注入方式，可在配置中用 {env:CZ_TOKEN} 引用cz_live_xxxxxxxx
CZ_BASE_URLAPI 服务地址，私有化部署或代理场景使用https://api.caizhao-token.com
CZ_MODEL默认模型名，覆盖配置中的 model 键deepseek-chat
CZ_CONFIG自定义配置文件路径，优先级位于全局配置与项目配置之间/path/to/custom-config.json
 
# Windows PowerShell
$env:CZ_TOKEN = "cz_live_xxxxxxxx"
$env:CZ_BASE_URL = "https://api.caizhao-token.com"
$env:CZ_MODEL = "deepseek-chat"
$env:CZ_CONFIG = "D:\config\caizhao-custom.json"

# macOS / Linux
export CZ_TOKEN=cz_live_xxxxxxxx
export CZ_BASE_URL=https://api.caizhao-token.com
export CZ_MODEL=deepseek-chat
export CZ_CONFIG=/path/to/my/custom-config.json

变量替换 #

你可以在配置文件中使用变量替换来引用环境变量和文件内容，避免在配置中明文写入敏感信息。

{env:VARIABLE_NAME} — 环境变量

使用 {env:VARIABLE_NAME} 替换环境变量：

{
  "apiKey": "{env:CZ_TOKEN}",
  "model": "{env:CZ_MODEL}",
  "baseUrl": "{env:CZ_BASE_URL}"
}

如果环境变量未设置，它将被替换为空字符串。建议在部署脚本中提前校验必需的环境变量是否存在。

{file:path/to/file} — 文件内容

使用 {file:path} 引用文件内容：

{
  "apiKey": "{file:~/.secrets/caizhao-token-key}",
  "instructions": ["./custom-instructions.md"],
  "notify": {
    "webhookUrl": "{file:~/secrets/notify-hook-url}"
  }
}

文件路径可以是：

  • 相对于配置文件所在目录的路径；
  • 以 / 或 ~ 开头的绝对路径。
i
典型用法：① 将 API Key 等敏感数据保存在单独文件中；② 引入大型指令文件而不会使配置变得杂乱；③ 在多个配置文件之间共享通用配置片段。

六大核心能力，开箱即用：

通过共同投标记录与中标统计识别竞争对手，输出竞争格局、优势区域与投标策略建议。
业主分析
查询采购单位画像与历史采购记录，定位目标客户、评估合作机会，匹配供应商与中标方。
商机预测
从拟建项目、采购意向、临期续约中提前发现早期商机，为招标项目智能推荐潜在供应商。
合同查询
获取标讯完整正文、附件与联系人字段，查看历史中标价格趋势，辅助报价与成本控制。

MCP 功能概述 #

采招词元 MCP（Model Context Protocol）服务器将招投标数据查询能力封装为标准工具，供 Cursor、TRAE、Claude Desktop 等支持 MCP 的 AI 工具直接调用。

相比传统 API 接入，MCP 具备四大优势：

  • 自然语言交互：用日常语言描述需求，AI 自动选择合适的工具与参数，无需手写请求；
  • 即时响应：无需在 AI 工具与数据接口之间复制粘贴，数据直达对话与分析流程；
  • 安全可控：工具调用按接口单价计费，权限与配额可控，数据合规可审计；
  • 持续更新：新能力发布后自动生效，无需升级 AI 工具或重新配置。

工作流程：

① 配置服务器
在 AI 工具中接入采招词元 MCP 服务器并填入 API Key。
② 自然语言提问
直接用对话描述查询需求，例如「帮我搜索最近北京地区关于智慧城市的招标项目」。
③ AI 调用工具
AI 助手自动选择并调用对应工具完成数据查询与聚合分析。
④ 获取结果
结构化结果返回对话，可直接对比、汇总或生成分析报告。

MCP 工具覆盖六大能力，按场景分为五类：

MCP 安装配置 #

按照以下步骤在您的 AI 工具中配置采招词元 MCP 服务器。

前置要求

  • 已获取采招词元 API Key（点击获取，新用户注册赠送 200 积分）；
  • 支持 MCP 的 AI 工具（Cursor、TRAE、Claude Desktop 等）。

步骤 1：获取 API Key

登录采招词元 AI 开放平台 → 个人中心 → API Key 管理 → 点击「创建新 Key」，复制生成的 API Key。API Key 具有调用接口的完整权限，请妥善保管。

步骤 2：配置 MCP 服务器

采招词元提供两种接入方式，任选其一：

方式 A：远程 MCP（推荐）——使用 Streamable HTTP 传输的远程服务器，地址为：

https://mcp.caizhao-token.com/mcp

以 Cursor 为例：打开设置（Cmd/Ctrl + ,）→ 搜索 MCP 或进入 Features → MCP → 点击 Edit Config，将以下配置添加到 mcp.json，替换 你的API_KEY 后保存并重启 Cursor：

{
  "mcpServers": {
    "caizhao": {
      "transport": "streamable-http",
      "url": "https://mcp.caizhao-token.com/mcp",
      "headers": {
        "X-API-Key": "你的API_KEY"
      }
    }
  }
}

方式 B：本地 MCP——通过 npx 启动本地服务器，适合需要自定义端点的场景：

npx -y @caizhao/token-mcp

步骤 3：验证配置

在 AI 助手中输入以下内容：

帮我搜索最近关于"智慧城市"的招标项目

如果配置正确，AI 助手会调用搜索工具并返回相关招标信息。

使用示例

  • 搜索招标项目：帮我搜索最近北京地区关于智慧城市的招标项目
  • 查询公司画像：查一下华为技术有限公司的中标情况
  • 价格趋势分析：帮我查看服务器采购的价格趋势
  • 智能推荐供应商：我们要采购一批办公家具，预算 50 万，帮我推荐一些供应商
i
使用技巧：描述需求时尽量具体，包含地区、行业、时间等关键信息；可在一次对话中进行多轮查询，AI 会记住上下文；结果不满意时，可要求 AI 调整搜索条件重新查询。

API 概述 #

采招词元 AI 开放平台通过统一的 HTTP 接口暴露全部能力：所有接口均为 POST，路径为 /api_v2/{tool_name}，使用 X-API-Key 鉴权。

Base URL

https://api.caizhao-token.com

完整请求地址示例：https://api.caizhao-token.com/api_v2/search_bids

认证方式

所有请求须在 Header 中携带 API Key（非 Bearer Token）：

X-API-Key: YOUR_API_KEY
  • 获取 API Key：在个人中心创建，新用户注册赠送 200 积分；
  • 安全传输：请使用 HTTPS；
  • 按积分计费：每个接口单价不同，以返回的 cost_units 积分为准。

快速开始

以下示例调用「搜索招中标」工具：

curl -X POST "https://api.caizhao-token.com/api_v2/search_bids" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "keywords": ["智慧城市", "信息化"],
    "page": 1,
    "page_size": 20
  }'

响应格式

统一 JSON 结构如下：

{
  "success": true,
  "data": { },
  "error": null,
  "meta": {
    "request_id": "req_abc123",
    "tool_name": "search_bids",
    "cost_units": 1,
    "execution_time_ms": 128
  }
}

失败时 success 为 false，error 含错误码与说明：

{
  "success": false,
  "data": null,
  "error": {
    "code": "INVALID_REQUEST",
    "message": "keywords 不能为空"
  },
  "meta": {
    "request_id": "req_xyz789",
    "tool_name": "search_bids",
    "cost_units": 0,
    "execution_time_ms": 12
  }
}

错误码

错误码说明
AUTHENTICATION_FAILEDAPI Key 无效、缺失或无权访问
INSUFFICIENT_BALANCE账户余额或可用次数不足
RATE_LIMITED触发频率限制
INVALID_REQUEST请求参数不合法或缺少必填项
INTERNAL_ERROR服务内部错误
TOOL_EXECUTION_ERROR工具执行失败（下游或业务逻辑异常）

频率限制

每个 API Key：每秒最多 5 次请求，每小时最多 2000 次请求。超出限制将返回 RATE_LIMITED，需降低并发或联系商务提升配额。
